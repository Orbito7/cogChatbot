# 🧠 Cognitive Bias Chatbot

A simple web-based chatbot that simulates three common cognitive biases: **confirmation bias**, **negativity bias**, and **optimism bias**. Built using vanilla **HTML, CSS, and JavaScript**, this project demonstrates how rule-based systems can mimic patterns of human reasoning and conversational behavior.

## 🎯 Features

- Chat interface that responds to user input based on selected bias
- Toggle between bias modes to see how response tone shifts
- Dynamic descriptions of each bias for educational context

## 💡 Why This Project

This project was created as part of my application to the UBC Cognitive Systems (COGS) program. It explores how simple computational systems can be used to simulate human-like behavior (a core interest of cognitive science).

## 🛠 Tech Stack

- HTML for structure
- CSS for styling
- JavaScript for logic handling

## 🧪 Bias Modes

- **Confirmation Bias**: Agrees with and reinforces whatever the user says
- **Negativity Bias**: Emphasizes potential problems or risks
- **Optimism Bias**: Highlights potential success or positive outcomes
